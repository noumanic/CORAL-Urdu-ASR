📊 Evaluation Metrics Overview

Introduction

In Automatic Speech Recognition (ASR), especially for Urdu language, we use several mathematical metrics to evaluate model performance. These metrics help us understand accuracy, error rates, and confidence calibration.

Core Metrics Used:

Metric Purpose Range Best Value
WER Word Error Rate - Measures word-level accuracy 0% to ∞ 0% (perfect)
CER Character Error Rate - Measures character-level accuracy 0% to ∞ 0% (perfect)
ECE Expected Calibration Error - Measures confidence reliability 0 to 1 0 (perfect calibration)
Edit Distance Minimum operations to transform hypothesis to reference 0 to ∞ 0 (identical)

🎯 Why These Metrics Matter for Urdu ASR:

  • Urdu has complex morphology and script variations
  • Character-level metrics (CER) are crucial for Urdu's connected script
  • Word-level metrics (WER) evaluate semantic accuracy
  • Confidence calibration ensures model reliability

📐 Edit Distance (Levenshtein Distance)

Foundational Metric

Edit Distance measures the minimum number of single-character (or word) edits required to transform one sequence into another. It's the foundation for WER and CER calculations.

Formula:

$$\text{EditDistance}(s_1, s_2) = \min \begin{cases} \text{EditDistance}(s_1[1:], s_2[1:]) + \mathbb{1}_{s_1[0] \neq s_2[0]} \\ \text{EditDistance}(s_1[1:], s_2) + 1 & \text{(deletion)} \\ \text{EditDistance}(s_1, s_2[1:]) + 1 & \text{(insertion)} \end{cases}$$

Three Operations:

Substitution

Replace one character/word with another

Deletion

Remove a character/word

Insertion

Add a character/word

Urdu Example:

Reference: یہ کتاب ہے
Hypothesis: یہ کتب ہے
Edit Distance: 1 (substitution: کتاب → کتب)

📝 Word Error Rate (WER)

Primary ASR Metric

WER is the most commonly used metric in speech recognition. It measures the percentage of words that were incorrectly transcribed at the word level.

Formula:

$$\text{WER} = \frac{\text{EditDistance}(R_{\text{words}}, H_{\text{words}})}{|R_{\text{words}}|} \times 100\%$$

Or equivalently:

$$\text{WER} = \frac{S + D + I}{N} \times 100\%$$

Where:

S

Number of substitutions

D

Number of deletions

I

Number of insertions

N

Total words in reference

Urdu Speech Recognition Example:

Reference: میں نے کتاب پڑھی ہے
Hypothesis: میں کتاب پڑھا ہے

Analysis:
• Deletion: نے (1)
• Substitution: پڑھی → پڑھا (1)
• Total reference words: 5

WER = (0 + 1 + 1) / 5 = 0.40 = 40%

🎯 Key Points:

  • Lower WER = Better performance
  • WER can exceed 100% if many insertions occur
  • Sensitive to word boundary detection in Urdu
  • Industry standard: WER < 10% is excellent

🔤 Character Error Rate (CER)

Fine-Grained Metric

CER measures accuracy at the character level, making it particularly useful for languages like Urdu with connected scripts and diacritical marks.

Formula:

$$\text{CER} = \frac{\text{EditDistance}(R_{\text{chars}}, H_{\text{chars}})}{|R_{\text{chars}}|} \times 100\%$$

Or:

$$\text{CER} = \frac{S_c + D_c + I_c}{C} \times 100\%$$

Where:

Sc

Character substitutions

Dc

Character deletions

Ic

Character insertions

C

Total characters in reference

Urdu Character-Level Example:

Reference: سلام (4 characters: س ل ا م)
Hypothesis: سلم (3 characters: س ل م)

Analysis:
• Deletion: ا (1 character)
• Total reference characters: 4

CER = 1 / 4 = 0.25 = 25%

🎯 Why CER Matters for Urdu:

  • Urdu uses connected script (Nastaliq)
  • Diacritical marks (aerab) affect meaning
  • CER captures subtle transcription errors
  • More granular than WER for morphologically rich languages
  • Typical good performance: CER < 5%

🎯 Expected Calibration Error (ECE) - Part 1

Confidence Calibration

ECE measures how well a model's confidence scores align with its actual accuracy. A well-calibrated model should be 80% accurate when it's 80% confident.

Formula:

$$\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$

Where:

M

Number of bins (typically 10)

Bm

Set of predictions in bin m

|Bm|

Number of predictions in bin m

N

Total predictions

acc(Bm)

Actual accuracy in bin m

conf(Bm)

Average confidence in bin m

Binning Process:

💡 How Binning Works:

Confidence range [0, 1] is divided into M bins:

Bin 1: [0.0, 0.1]
Bin 2: (0.1, 0.2]
Bin 3: (0.2, 0.3]
...
Bin 10: (0.9, 1.0]

Each prediction is assigned to a bin based on its confidence score.

🎯 Expected Calibration Error (ECE) - Part 2

Calculation Example

Step-by-Step Calculation:

💡 Urdu ASR Example:

Suppose we have 100 word predictions from Whisper model:

Bin 5 (0.4-0.5 confidence):
• 15 predictions fall in this bin
• Average confidence: 0.45
• Actual correct predictions: 6
• Accuracy: 6/15 = 0.40

Contribution to ECE:
(15/100) × |0.40 - 0.45| = 0.15 × 0.05 = 0.0075
$$\text{For each bin: } \frac{|B_m|}{N} \times |\text{acc}(B_m) - \text{conf}(B_m)|$$

$$\text{acc}(B_m) = \frac{\text{Number of correct predictions in bin}}{|B_m|}$$

$$\text{conf}(B_m) = \frac{1}{|B_m|} \sum_{i \in B_m} p_i$$

🎯 Interpretation:

  • ECE = 0: Perfect calibration
  • ECE < 0.05: Well calibrated
  • ECE > 0.15: Poorly calibrated
  • Over-confident: conf > acc
  • Under-confident: conf < acc

Why ECE Matters for Urdu ASR:

When transcribing: میں اسکول جاتا ہوں

If model says "80% confident" but only correct 50% of time,
users can't trust the confidence scores!

Good calibration → Reliable confidence → Better user experience

💻 Implementation in Python

Code Reference

WER Implementation:

def compute_wer(reference: str, hypothesis: str) -> float: ref_words = reference.split() hyp_words = hypothesis.split() if len(ref_words) == 0: return 0.0 if len(hyp_words) == 0 else 1.0 edit_dist = editdistance.eval(ref_words, hyp_words) return edit_dist / len(ref_words)

CER Implementation:

def compute_cer(reference: str, hypothesis: str) -> float: if len(reference) == 0: return 0.0 if len(hypothesis) == 0 else 1.0 edit_dist = editdistance.eval(reference, hypothesis) return edit_dist / len(reference)

ECE Implementation:

def compute_ece(confidences: np.ndarray, accuracies: np.ndarray, n_bins: int = 10) -> float: bin_boundaries = np.linspace(0, 1, n_bins + 1) ece = 0.0 for i in range(n_bins): in_bin = (confidences > bin_boundaries[i]) & \ (confidences <= bin_boundaries[i + 1]) prop_in_bin = in_bin.mean() if prop_in_bin > 0: accuracy_in_bin = accuracies[in_bin].mean() avg_confidence_in_bin = confidences[in_bin].mean() ece += abs(avg_confidence_in_bin - accuracy_in_bin) * prop_in_bin return ece

📋 Summary & Best Practices

Quick Reference

Metric Comparison:

Metric Formula Excellent Good Poor
WER EditDist(words) / N_words < 5% 5-15% > 30%
CER EditDist(chars) / N_chars < 2% 2-10% > 20%
ECE Σ |acc - conf| × weight < 0.05 0.05-0.10 > 0.15

🎯 Best Practices for Urdu ASR Evaluation:

  • Always report both WER and CER for Urdu
  • Use character-level metrics for script analysis
  • Monitor ECE to ensure confidence reliability
  • Test on diverse Urdu dialects and accents
  • Normalize text before computing metrics
